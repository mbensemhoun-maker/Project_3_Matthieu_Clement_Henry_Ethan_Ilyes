# Exemples pour le notebook

Ces trois JSON ont été **saisis à la main** à partir des CV fictifs de test
`01_lea_vasseur`, `04_hugo_lefebvre` et `10_kevin_dubreuil`, disponibles dans
`datas_extract/`. Ce ne sont pas des réponses d’un modèle.

Ils servent à exécuter le notebook sans clé API et à tester le nouveau format.
Ils illustrent trois profils différents ; ils ne représentent pas les 11 CV.
Les analyses et exports portent explicitement la mention « exemples ».

Les vraies réponses du pipeline iront dans `sorties/`. Ne pas mélanger les
exemples à ce dossier pour augmenter artificiellement l’effectif.
